# Jamil Chowdhury — personal website

Website: https://jamil-chowdhury.github.io/

GitHub Pages publishes the root of `main`.

The landing page retains the illustrated farm panorama and generated grey felt background. The name uses self-hosted Bodoni Moda in dark green, with the subtitle `Research. Creative technologist. Artist.`

## Editing

- Edit `h1#name` in `index.html` to change the name and `.identity-line` to change the subtitle.
- `assets/content.css` contains the identity and prepared animation-card/video-page styles. Font licenses are bundled in assets.
- The farm artwork and its pause/play control remain in `index.html`. Rendering pauses while hidden or offscreen, and reduced motion starts the farm paused.

## Prepared animation update

The `animation-windows-ready` branch contains the first animation card and its separate video page, plus instructions for future additions. Publish its video asset to the `animations-v1` GitHub release before merging that branch. The required file is `ectomycorrhiza-1080p.mp4` (85,291,334 bytes). This keeps the homepage free of a broken video link while upload is pending.
