# Jamil Chowdhury — personal website

Website: https://jamil-chowdhury.github.io/

GitHub Pages publishes the root of `main`.

The landing page uses the supplied `landing page(1).html` farming panorama. Its artwork, labels, animated farm life and generated grey felt texture are retained. Only Jamil Chowdhury is added beneath the banner.

## Editing

- `index.html` contains the homepage CSS and both canvas scripts. The farm illustration is a 3:1 panorama. The grey background is generated by the final script.
- Edit `<h1 id="name">` to change the name.
- Add future blog or animation sections inside `<main id="sections">`, after the name. A commented example is included there.
- Handwritten labels and farm objects are drawn by the first script. Search the label wording to edit an annotation.
- `assets/caveat-subset.ttf` is the self-hosted Caveat font; see `assets/OFL-Caveat.txt` for its license.

The pause button sits below the artwork. Reduced motion starts the farm paused. Animation rendering stops while the tab is hidden or the banner is offscreen. Mobile uses the supplied crop to keep the gardener and child visible. There are no external font or script requests.
