# Design: Jamil Chowdhury

Preserve the supplied 3:1 felt-and-ink farming panorama, its scientific labels, animated farm life, original crop and generated grey felt background.

The identity sits inside the banner, in the open sky at the top-left, in dark green (#173e2c). A large headline `The unsung heroes of my farm` uses self-hosted Fraunces (soft, slightly irregular botanical serif); below it, in smaller self-hosted Kalam handwriting, `Creator: Jamil Chowdhury` and the exact subtitle `Researcher. Creative technologist. Artist.` Farm illustration labels retain Caveat.

A responsive animation gallery follows the banner, with up to four small windows per row on wide screens, centred. Each card has a still thumbnail in a stitched felt frame, held to the felt board by semi-transparent masking tape with torn ends (placement varies card to card: both top corners, one strip across the top, a long corner piece, or two uneven strips; the pattern repeats every four cards); the windows sit slightly uneven, as if pinned by hand: each frame has a small tilt (up to about 2°) and a different drop and sideways nudge (cycle of five), while titles stay level, a 50%-opaque play symbol, Jamil's credit, a title in self-hosted Fraunces (soft, slightly irregular botanical serif) and a brief description in self-hosted Kalam (field-notebook handwriting). It opens a separate page through a normal link with `target="_blank" rel="noopener"`; the visitor's browser chooses a new tab or window.

The first animation is `A Partnership Takes Root`, subtitled `What ectomycorrhiza is and how it forms.` Its separate page has a native video player and a back-to-farm link (no name in the page header), with no download link. Video-page titles use Fraunces and the description, running time and back link use Kalam, matching the cards. The narrated MP4 is hosted as a GitHub release asset. The homepage loads only the poster image, and the player uses `preload="none"` with no autoplay.
